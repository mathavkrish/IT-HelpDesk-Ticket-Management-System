
# IT Help Desk Ticket Management System

A web-based IT support ticket management application built using Python, Flask, and SQLite.

## Features

- Create and manage IT support tickets
- Admin login and logout
- Secure password hashing
- Update ticket status
- Assign tickets to IT technicians
- Analytics dashboard with interactive charts
- Advanced ticket search and filtering
- Export ticket reports as CSV

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- Bootstrap
- JavaScript
- Chart.js

## Installation

1. Clone this repository.
2. Create a Python virtual environment.
3. Install dependencies:

   pip install -r requirements.txt

4. Create an admin account:

   python app.py create-admin

5. Start the application:

   python app.py

6. Open http://127.0.0.1:5000
